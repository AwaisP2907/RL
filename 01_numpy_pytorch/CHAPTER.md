# Chapter 1 — NumPy & PyTorch

**Dates:** Nov 23–29

## Objective

Get fluent with NumPy arrays and PyTorch tensors, autograd and training loops.

## Gate

- Write a PyTorch training loop from a blank file, without AI.
- Explain what `loss.backward()` and `optimizer.step()` do.

## Plan

### Topics

- NumPy arrays, indexing, broadcasting
- Neural network basics and backpropagation
- PyTorch tensors, autograd, `nn.Module`, optimizers, training loop

### Resources

- [NumPy: the absolute basics for beginners](https://numpy.org/doc/stable/user/absolute_beginners.html)

- [3Blue1Brown — Neural Networks](https://www.3blue1brown.com/topics/neural-networks) (Ch 1–4)
- Karpathy micrograd, first hour: [video](https://www.youtube.com/watch?v=VMj-3S1tku0) · [repo](https://github.com/karpathy/micrograd)
- [PyTorch — Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)

### Build

- `train_mlp.py`: fit a noisy sine wave with an MLP and plot train/val loss.
